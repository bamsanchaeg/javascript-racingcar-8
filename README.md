# 자동차 경주 게임

## 미션 개요

간단 자동차 경주 게임을 구현한다.

### 기능 요구 사항

- 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
- 각 자동차에 이름을 부여할 수 있다. (쉼표(,)로 구분)
- 자동차 이름은 5자 이하만 가능하다.
- 사용자는 몇 번의 이동을 할 것인지 입력할 수 있어야 한다.
- 전진 조건: 0~9 사이의 무작위 값이 4 이상일 경우 전진한다.
- 모든 라운드 종료 후 우승자를 출력한다. (여러 명일 수 있음)
- 잘못된 입력 시 `[ERROR]`로 시작하는 메시지 출력 후 종료한다.

---

## 기능 목록

1. **입력 기능**

   - [ ] 자동차 이름 입력받기 (`네오,브리,코코` 형식)
   - [ ] 시도 횟수 입력받기

2. **입력 검증**

   - [ ] 자동차 이름이 5자 이하인지 검증
   - [ ] 빈 문자열 또는 공백 입력 시 에러 처리
   - [ ] 시도 횟수가 양의 정수인지 검증

3. **게임 진행 로직**

   - [ ] 자동차 객체 생성 (이름, 위치)
   - [ ] 각 라운드마다 0~9 난수 생성 후 4 이상이면 전진
   - [ ] 진행 상황을 라운드별로 출력

4. **우승자 결정**

   - [ ] 가장 많이 전진한 자동차 찾기
   - [ ] 우승자가 여러 명일 경우 쉼표로 구분하여 출력

5. **출력 기능**

   - [ ] 각 라운드별 결과 출력
   - [ ] 최종 우승자 출력

6. **에러 처리**
   - [ ] `[ERROR]`로 시작하는 메시지와 함께 예외 발생 후 종료
